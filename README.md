# 금수저 윤이님의 그지병원 탐험기

심장내과 전임의 개인용 업무 관리 PWA(설치형 웹앱). 1인 비공개 사용.

## 기능
- **할 일**: 위치(병동·CCU·심도자실·외래)·분류(응급·회진·행정)·시술(CAG·PCI·Echo·CCTA) 태그, 트리아지 정렬, 마감 알림용 시간 기록
- **연락처**: 다차원 태그(교수·전임의·PA/기사/간호사·외래·Q), 당직자 상단 고정, 내선/개인번호 원터치 전화, 폰 주소록 저장(vCard)
- **자료함**: 공문서·캡처 사진 압축 저장 + 문자인식(OCR) 검색 + 공유/내보내기
- **신촌세브란스 응급실 현황**: 국립중앙의료원 E-Gen 공공데이터 실시간 조회
- 다크모드, 오프라인 작동(IndexedDB·서비스워커), JSON 백업/복원

## 사용 방법
이 저장소를 GitHub Pages로 게시하면 `https://<사용자명>.github.io/<저장소명>/` 에서 열립니다.
휴대폰 크롬에서 열고 "홈 화면에 추가" 하거나, PWABuilder로 설치 패키지를 만들 수 있습니다.

## 구조
- `index.html` — 앱 전체(HTML·CSS·JS·매니페스트·아이콘·서비스워커가 모두 이 한 파일에 포함)

## 주의
의료 진단·치료 목적이 아닌 개인 업무 관리용 도구입니다. 환자 식별정보는 입력·저장하지 않도록 합니다.
